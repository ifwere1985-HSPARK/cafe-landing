# cafe-landing

가상의 카페 **Bean & Bloom**의 간단한 랜딩 페이지입니다. 별도의 빌드 도구나 라이브러리 없이 순수 HTML/CSS로만 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 및 모바일 대응 (반응형) |
| `README.md` | 프로젝트 설명 (현재 문서) |

## 실행 방법

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

```bash
start index.html   # Windows
```

## 참고

- 메뉴, 가격, 주소는 모두 예시 데이터입니다.
- AI Agent 수업 실습용으로 Claude Code를 이용해 생성했습니다.
